# TikTok АвтоСвайп

Android-приложение (служба спец. возможностей): когда видео в TikTok заканчивается — свайпает вверх.

## Как получить APK без Android Studio
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки (вместе с .github).
2. Вкладка Actions → Build APK → дождитесь зелёной галочки.
3. Внутри запуска скачайте артефакт autoswipe-apk → app-debug.apk.

## Как собрать в Android Studio
Open → выберите папку проекта → Build → Build APK(s).

## Установка и запуск
1. Установите APK (разрешите установку из неизвестных источников).
2. Android 13+: Настройки → Приложения → TikTok АвтоСвайп → ⋮ → «Разрешить ограниченные настройки».
3. Откройте приложение → «Открыть настройки спец. возможностей» → включите «TikTok АвтоСвайп».
4. Вернитесь в приложение, включите переключатель «Автосвайп включён», откройте TikTok.
